# rng-vfx for any coding agent

This repository is a game VFX skill. When a task involves visual effects (hits, slashes, impacts, projectiles, explosions, fire, smoke, magic, auras, lightning, trails) or their shaders, particles, timing or performance:

1. Read `skills/rng-vfx/SKILL.md` and follow its process.
2. Read the style file for the requested style, and the other reference files when the process points to them.
3. Review the result on stills and on consecutive frames. For a web effect with the `window.fx` API, `python skills/rng-vfx/scripts/capture_strip.py <folder> <out>` renders both.
